# SKILL: 编写文档

**触发**：用户要求写文档、补文档、更新文档、添加示例。

## 原则

- 文档与代码同步：新增或修改公开 API 时，docstring 与文档载体（README / `docs/` / 示例）一并更新
- 保持项目既有的语言策略与术语；双语项目需镜像同步
- 示例代码必须可运行：先验证，再写入文档

## 步骤

1. 确定公开 API 对应的文档载体与位置。
2. 更新 docstring：只描述公开行为（用途、参数、返回值、异常）。
3. 更新 README / `docs/` 中的说明与示例，并同步索引或导航条目。
4. 运行项目验证链，确认文档中的命令与示例可用。

# TEMP FILE RULE — 临时文件规则

## 用途

临时文件用于存放**当前会话**中产生的中间产物。会话结束后可清理，不应提交到版本控制。

## 存放位置

所有临时文件一律放入 `.agents/TEMP_FILES/tmps/` 目录。

## 何时创建临时文件

以下场景应使用临时文件，避免污染项目目录或依赖系统临时路径：

| 场景 | 示例 |
| --- | --- |
| 调试输出 | 捕获命令 stdout/stderr 供后续分析 |
| 中间产物 | 代码生成前的草稿、格式转换中间文件 |
| 验证脚本 | 一次性测试脚本、实验性代码片段 |
| 性能分析 | profiler 输出、覆盖率中间报告 |
| 差异对比 | 重构前后的代码快照 |
| 命令记录 | 会话执行的命令序列备份 |

## 命名规范

```text
tmps/<描述>_<时间戳>.<扩展名>
```

- `<描述>`：简明的英文小写 + 下划线，如 `debug_handler_output`
- `<时间戳>`：`YYYYMMDD_HHMMSS`
- 仅在需要长期保留时才省略时间戳

## 生命周期

- **开始前**：清理 `tmps/` 中与当前任务无关的旧临时文件
- **创建**：任务需要时随时创建
- **任务完成**：立即删除本次任务产生的临时文件
- **会话结束**：清空 `tmps/`（目录保留）
- **不提交**：`tmps/` 已在 `.gitignore` 中排除

> 若临时文件中的内容具有持久价值（如用户偏好、重要决策记录），应写入 `.agents/MEMORY/memorys/` 而非留在 `tmps/`。

## 禁止事项

- 禁止在 `tmps/` 外创建临时文件（如项目根目录、`src/`、`tests/`）
- 禁止将 `tmps/` 中的文件作为持久化存储（应使用 `.agents/MEMORY/memorys/`）
- 禁止在临时文件中写入敏感信息（密钥、token 等）
